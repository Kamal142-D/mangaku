# Mangaku source recovery

These notes describe the original 1.5.3 recovery. For the current 1.6.0
build, see [BUILD.md](BUILD.md); for the inspected data model, see
[DATA_FLOW.md](DATA_FLOW.md).

This workspace was reconstructed from the published Mangaku 1.5.3 APK after
the original source tree was lost.

## Verified input

- APK: `builds/original/mangaku-v1.5.3.apk`
- SHA-256: `ae4ef83fa163d0efc7899b6340b3050123bca51948f7c7a2f85217e4515947bc`
- Package: `com.mangaku.app`
- Version: 1.5.3 (version code 9)
- Embedded Git revision: `2b42a38937951fa913623be5059b5c3adb3893a5`

The embedded revision is not present in the public repository, so an exact Git
checkout could not be recovered.

## Recovered material

- `android-project/`: readable JADX export containing 4,522 Java files and
  1,163 resource files.
- `recovery/decompiled/fallback-sources/`: low-level output for all 4,523
  classes. It has no `Method not decompiled` or `JADX ERROR` gaps.
- `recovery/raw/apk/`: expanded APK bytecode, resources, assets, and libraries.
- `recovery/decompiled/mangaku-v1.5.3.jobf`: generated deobfuscation map.
- `recovery/config/sources.json`: selector configuration reconstructed from
  constants in the APK.
- `recovery/work/apktool-project/`: rebuildable APK bytecode project.

## Applied fix

The IMHentai search code no longer retries a valid empty filtered response with
an unfiltered request. Categories, languages, and sorting therefore remain
applied when a query has no matches.

The installable test build is:

`builds/test/mangaku-v1.5.3-imhentai-filter-test.apk`

SHA-256:
`4c72d78a56ff2e0be2e642b8adb92f47928b9e1bdc9896bd3f75064a03fbad6a`

It is signed with an Android debug certificate. It cannot replace the published
release-signed installation; back up app data and uninstall the published build
first, or test it on a separate device/profile.

## Recovered build facts

- Kotlin/Jetpack Compose Android application
- Android Gradle Plugin 8.5.2 and Gradle 8.7
- Kotlin 1.9.24, Java target 17
- compile/target SDK 34, minimum SDK 26
- Compose 1.6.8 and Material 3 1.2.1

The Gradle files generated by JADX are only a scaffold. Dependencies, original
Kotlin formatting, tests, comments, symbol names, and Git history are not
recoverable from an APK. Preserve the fallback source while rebuilding clean
features from the readable project.

The original signing key also cannot be recovered from the APK. Publishing an
update under the same package requires the original keystore or Play App
Signing access.
